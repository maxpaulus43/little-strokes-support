# Little Strokes support and privacy

Static public support, privacy, and licensed character-data pages for Little Strokes: Hanzi Practice.

Public site: https://maxpaul.us/little-strokes-support/

GitHub Pages uses the account's existing custom domain. The GitHub Pages URL https://maxpaulus43.github.io/little-strokes-support/ redirects to the HTTPS public site.

Support: support@chefness.org

This repository contains the support website and redistributable licensed character data with its processing scripts. The Swift app source is maintained separately in a private repository. This site has no accounts, analytics, forms, or user handwriting; optional sync in the app is described on the privacy page.
