Character data & source

The character library is freely reusable under its upstream licenses. Little Strokes bundles 9,574 characters from Make Me a Hanzi, revision bddc96d.

Dictionary records derive from Unihan and CJKlib and are distributed under LGPL 3 or later. Stroke graphics derive from Arphic PL KaitiM GB and Arphic PL UKai and are distributed under the Arphic Public License. Copyright © 1999 Arphic Technology Co., Ltd.

October 8, 2026: original records were repackaged in SQLite with normalized search keys. October 10, 2026: 340 English definitions and their search keys were filtered for family use, including selected neutral meanings for common characters. All characters, pinyin, stroke geometry, and original JSON records are preserved.

The original dictionary records in this downloadable source are unfiltered and include adult vocabulary. Those original records are kept for licensed-data reuse and are not the definitions shown during practice.

  • Bundled SQLite character library (gzip)
  • Rebuild script and family definition rules (save both in the same Scripts directory)
  • Original-record export script
  • Copyright and modification notices
  • Upstream licensing notice, LGPL, GPL, and Arphic Public License

To rebuild, put the scripts in a Scripts directory and run the rebuild script with Python 3. It downloads the pinned upstream records and writes HanziPractice/Resources/hanzi.sqlite in the parent directory. The export script writes original JSON records and licenses from that layout. These downloads contain character data, never a user's saved handwriting.
